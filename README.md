## The sentence

> The old map promised gold at the end of the desert, so I followed it past bleached bones and dry wells for forty days, and when I finally dug where the X was marked, I found a mirror, and laughed, because the treasure had been the thirst that kept me walking.

One sentence, 259 characters. A complete journey in a single breath: a map's promise sends the traveller across the desert, forty days past bleached bones and dry wells, to the marked spot — where the gold turns out to be a mirror, and the real treasure the thirst that kept him walking.

## How it works

`main.py` (Python 3.13, standard library only) writes the sentence to `/output/entry.txt`. Run it with:

```sh
python3 -P -s main.py
```
